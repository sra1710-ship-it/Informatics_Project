# Informatics_Project
5-сыныпқа арналған платформа: авторлық ойын тапсырмалары мен интерактивті жаттығулар арқылы оқушылардың алгоритмдік ойлауын дамытуға бағытталған. Жүйе "Роботты басқару", "Лабиринт" секілді тапсырмалар арқылы қадамдық нұсқау құруды үйретіп, багтарды түзету (debugging) және лездік кері байланыс алу арқылы білім сапасын арттырады.
